# SPACE.CADET // Konami disk 05

The three binaries in this folder are a prebuilt Emscripten build, taken verbatim
from the `gh-pages` branch of the upstream project:

- `SpaceCadetPinball.js`
- `SpaceCadetPinball.wasm`
- `SpaceCadetPinball.data`

Source: <https://github.com/alula/SpaceCadetPinball> (branch `gh-pages`, downloaded 2026-09-05)

- Decompilation of *3D Pinball for Windows - Space Cadet*: **k4zmu2a/SpaceCadetPinball**, MIT.
- WebAssembly / SDL2 port and this build: **alula/SpaceCadetPinball**, MIT. Upstream demo: <https://pinball.alula.me>

`index.html` and `style.css` are ours: the DAIVR cabinet shell (boot overlay,
touch pads, Escape bridge to the arcade modal). The MIT licence covers the port's
own code; the table art, sounds and `.DAT` resources packed into
`SpaceCadetPinball.data` are Microsoft's original game assets and are not
licensed by either project.

To update the build, re-download the three files from the branch above. Nothing
in this folder is generated by the site build - Vite copies `public/` verbatim.
